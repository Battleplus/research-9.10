# 异步事件观测下的奖励机器研究任务书

> 状态：保留为早期备选资料，下文的排序或主线称谓属于原方案。当前优先决策以[连续研究路线](continuous-research-roadmap.md)为准。

这是快速验证备选任务，研究主线另见离线多智能体任务书。目标是验证一个窄问题是否值得继续，不以生成论文页数为完成标准。初步目标是形成可面向 A−／A 候选 venue 讨论的研究证据，不能预承诺档位。

**资源与范围**

RTX 4060 与 H200 可用。该题仍先采用可人工核算的事件序列及轻量服务机器人网格任务，小网络验证问题，随后再扩大实验。首轮无需大模型微调，不依赖实体机器人。完整机器人论文是否需要补充平台实验，在 pilot 之后判断。

**研究问题**

事件“发生时间”与“观测结果到达时间”不一致时，在仅使用已经到达的信息条件下，奖励机器状态推断如何恢复正确任务进度？有限窗口的修订机制是否在相同计算预算下改善真实任务成功率？

这不是已经确认的新问题。至少要查阅并对照：

- [Reward Machines for Deep RL in Noisy and Uncertain Environments](https://arxiv.org/abs/2406.00120) 与[作者实现](https://github.com/andrewli77/reward-machines-noisy-environments)，重点核对 TDM，不能把已有的时序依赖处理写成新贡献。
- [Learning Robust Reward Machines from Noisy Labels](https://proceedings.kr.org/2024/85/kr2024-0085-parac-et-al.pdf)，区分结构学习与状态推断。
- [Active Reward Machine Inference From Raw State Trajectories](https://arxiv.org/abs/2604.07480)，区分主动机器推断与在线延迟观测处理。
- 固定滞后平滑、乱序观测更新、POMDP 状态估计与在线时序逻辑监控的近邻方法；这一部分尚需系统补查，发现等价方法时应改题。

**候选假设**

H1：有限窗口修订比按到达顺序推进更少发生不可恢复的任务状态误判。

H2：在相同可用观测、相同窗口和相近计算成本下，奖励机器结构能带来超越通用序列估计或简单排序的收益。

H3：状态估计改善能够提高完整任务成功率，并且不会付出抵消收益的决策延迟。

H1 单独成立不足以成为新方法论文。H2 是主要研究差异，H3 是应用价值；每个都允许被否定。

**先做离线事件测试**

设计可手工核算的顺序任务，事件数据保存真实发生时间、可见的时间标记、到达时间、观测值与置信信息。真实事件与隐藏状态放在评估侧；方法输入只能包含当前已经到达的消息。

先用无噪声条件隔离到达延迟问题，再增加误检与漏检，避免一开始混合过多因素。延迟幅度、乱序程度和噪声参数作为明确输入，不从实验结果反推“最佳设定”。若部署中没有可靠事件时间标记，必须加上未知或带误差时间标记的条件，不能默认为可获得真值。

**最小对照**

| 对照 | 目的 |
|---|---|
| 无延迟、正确标签的 oracle | 仅作为理想参照，不能当可部署方法 |
| 按到达顺序直接更新 | 检查基本失败模式 |
| 缓存并按可见时间标记排序 | 排除简单工程处理已足够的可能 |
| 原论文 IBU／TDM，按公平输入适配 | 与最接近的已有方法比较 |
| 相同窗口的通用序列估计或固定滞后平滑 | 排除通用记忆／平滑解释 |
| 拟议有限窗口任务信念修订 | 待实现候选，不能提前填写结果 |

所有基线必须拿到相同可用时间信息。若某基线需要不同训练数据或额外监督，单独披露并设配对对照。

**再做闭环任务**

使用 [MiniGrid](https://github.com/Farama-Foundation/Minigrid) 风格的取送物、开门与顺序访问任务。先完成一个任务、一个小网络和一个固定协议；验证能训练后再扩到多任务。

主评价采用环境真实事件判定的完整任务成功率，另外报告状态误判率、错误持续时长、实际约束违反、推理延迟和训练样本数。方法内部生成的阶段奖励不能兼任最终正确性判据。

pilot 的候选默认规模为两类任务、三种延迟条件、三个配对种子；数值仅用于初步测量，正式种子数根据方差和可检测效应确定。测试轨迹长度和每次运行上限在基线测时之后冻结，不先承诺固定 GPU 小时。

**实验记录与统计**

每次保存：代码提交、环境版本、配置、种子、数据哈希、开始结束时间、退出状态、显存峰值、原始逐回合结果。相同随机环境配置用于方法间配对比较，测试地图与延迟采样序列不参与调参。

置信区间按独立训练运行或预先定义的任务层级计算，不能把同一策略的大量回合当作独立训练重复。若采用 bootstrap，说明重采样单位。失败运行保留原因；数值缺失不填零，不只展示最好种子。

**继续条件**

先查重，再冻结最小有意义改善与容忍成本。只有候选在强对照下有稳定证据，且增益不来自额外信息、更多计算或未来数据，才进入完整实验。具体阈值依据基线测量预先设定，不按结果挑选。

**停止条件**

- 发现等价已有方法，且没有新的问题设定、分析或系统证据。
- 排序缓存已经解决主要问题，复杂方法无额外价值。
- 只改善状态分类，闭环任务无益或明显更慢。
- 优势只出现在单一人工构造条件，其他条件恶化。
- 需要不可获得的时间真值、隐藏标签或未来信息。

停止时输出负结果与边界，保留可复现实验，不把失败包装成已完成的新方法。

**自动科研流程接口**

输入：主题、论文原文、代码版本、硬件、预算和评价口径。

输出依次为：literature_matrix.md、hypotheses.md、protocol.yaml、runs/、analysis/、decision.md。只有 decision.md 支持继续，才扩大研究范围；论文写作只消费已经核验的结果和文献。

最终稿件的每个主张都关联具体 run ID 或原文出处。候选 venue 先按研究内容筛选，机器人相关证据充分时讨论 ICRA／IROS（图片 A−）及 RA-L（图片 A）。纯网格实验不预判达到这些标准。
