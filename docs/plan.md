# 科研工作流执行规划

## 目标与现阶段决策

研究范围为计算机、AI、数据科学及通用民用机器人任务。当前优先考察“偏好强化学习 → 约束强化学习 → 世界模型”的连续路线，各阶段以 A− 档及以上为目标。详见[连续研究路线](continuous-research-roadmap.md)。离线多智能体、奖励机器和表格基础模型保留为备选；各阶段顺序推进，共享可信研究资产。

RTX 4060 用于开发与小规模验证，H200 用于基线训练、重复实验和规模扩展。H200 的可用时段、卡数、显存配额和软件环境仍需在排期前记录；拥有 GPU 不等于已具备某个基准的数据与实验条件。

## 系统组成

| 环节 | 初始方案 | 关键产物与验收 |
|---|---|---|
| 主题输入与文献整理 | 结构化研究简报，论文原文与引用核对 | 问题边界、文献矩阵、最接近工作 |
| 研究流程组织 | ARIS 作为拟采用入口 | 能保存决策、调用受控实验、失败后恢复；先做能力验收 |
| 点子与可行性分析 | 研究假设卡、反例和简单替代方案 | 可证伪问题、最低实验、失败条件 |
| 实验执行 | 偏好／约束学习实现待选型；独立环境与固定版本 | 一条命令复现、数据划分、完整配置和原始日志 |
| 结果分析 | 固定评价脚本、置信区间、消融 | 不只选择最好种子；统计单位明确 |
| 写作与审查 | 基于核验结果生成草稿、逐项核对引用 | 论断可追溯到实验或文献，保留局限和负结果 |
| 投稿准备 | 目标 venue 范围与格式核对 | 完整稿、补充材料、作者贡献和披露清单 |

ARIS 与所选实验框架的连接、GPU 调度、证据记录及写作约束需要实现和验证，目前没有完成端到端集成。上传本规划不代表已有一键科研系统。

## 阶段安排

以下是工作量估计，依赖代码和数据获得情况，不是完成或录用保证。

1. **资源确认，约 2–5 个工作日。** 每个候选收集 3–5 篇核心论文、最近工作、代码版本与运行命令、数据许可、已有结果、失败记录及指导条件。使用[讨论模板](../templates/resource-intake.md)，给出继续或暂缓结论。
2. **复现与查新，约 1–2 周。** 锁定一个基准、一个主要指标和可信基线；核对最接近论文及代码，复现差异在改方法前说明。先设实验预算，再开放自动迭代。
3. **最小验证，约 1–2 周。** 只验证一个假设。先诊断问题是否存在，再增加方法。至少比较简单修补与同预算基线；初筛后对关键结论采用多个随机种子确认。
4. **正式实验，约 3–6 周或更久。** 扩展任务、数据覆盖、错配强度和预算设置；补充消融、统计不确定性和失败案例。若面向机器人期刊，补足相应应用证据。
5. **写作与内部审查，约 2–3 周。** 从经验证的结果生成论证、图表与草稿；人工审阅新颖性、实验公平性、引用、作者贡献与目标要求。审稿周期另计。

## 自动执行边界与记录

文献去重、代码修改、预算内实验、图表及草稿可以逐步自动化。实验结果必须来自真实执行，无法完成的实验标为未完成。方法选择不能依赖测试集反复调参；调参预算对各方法可比。每次运行记录代码提交、依赖环境、数据来源和划分、配置、随机种子、设备、起止时间、日志、指标与异常。

研究建议、同行评议意见和投稿适配分析不等于事实。正式提交前需作者确认最终稿、作者顺序、版权和目标系统声明，再执行相应投稿操作；当前阶段只做规划和项目筛选。

## 投稿目标怎样判断

A−／A 沿用现有成果认定表，不能当作统一的学术等级或录用概率。JCR 分区、中科院分区、CCF 分类及课题组档位是不同体系，最终以当年名单和单位认定为准。

- 离线多智能体：如果主要是一般学习方法，可评估与贡献匹配的 AI／机器学习会议；如果有充分机器人应用证据，可评估 ICRA／IROS 或 RA-L。RA-L 的范围可查[官方说明](https://www.ieee-ras.org/publications/ieee-robotics-and-automation-letters/)。
- 奖励机器：根据实际贡献是推理、学习还是机器人执行，再选择相应会议或期刊，不能凭轻量网格实验直接推断 A 档。
- 表格基础模型：以跨数据集可靠性、预算公平性和方法新颖性为主要证据；先形成稿件贡献，再具体确定 venue。

每次选刊输出“范围匹配、最接近已发表论文、当前证据缺口、所需补实验、备选目标”，不输出无依据的录用概率。现阶段只是目标梯队，尚无实验支撑的档位评估。
